# ケモトレ

3人の獣人トレーナーと続ける、自宅筋トレ用PWAです。正本はルートの `index.html` です。

## v7 の中心機能

- シャドウ（黒猫）、ラン（ゴールデンレトリバー）、ゴウ（熊）の成人男性獣人イラストを既定画像として同梱
- 半リアルで筋肉質なトレーニングウェア姿に統一
- 設定画面のカスタム画像差し替えは従来どおり利用可能
- 3枚は透過WebPへ最適化し、Service Workerでオフライン保存

## v6 から継続：基本3種

- 種目はスクワット・腕立て伏せ・クランチの3つに固定
- 「胸・腕」「お尻・脚」「お腹」「バランス」から育てたい場所を選択
- 3分（最低限）・6分（基本）・10分以上（育てる）を選択
- 重点部位だけセット数を増やし、種目選びの迷いをなくす
- 終了後の「きつすぎた／ちょうどいい／余裕だった」で次回の回数を微調整
- 部位別の週間セット数を自動記録
- 強めの同部位トレーニングが近すぎる場合は回復の注意を表示

既存の38種目、フォーム・筋肉図鑑、3トレーナー、絆・EXP・実績、VOICEVOX再生、Web Speechフォールバック、画像差し替え、PWA機能は残しています。

## 起動

Webサーバーへ一式を置き、`index.html` を開いてください。HTMLをスマホのファイルアプリから直接開くだけでは、Service WorkerとPWAインストールが動かない場合があります。

録音済み音声はこのリポジトリに含まれていません。手元の既存 `voices/` フォルダをルートへ置くと、従来のファイル名のまま再生されます。音声がない場合は端末の読み上げへフォールバックします。

## 検証

```bash
node tests/smoke.mjs
```

構文、旧 `kemotore_v1` データ互換、基本3種の表示と重点配分、休憩設定、週間セット記録を検査します。

## 主なファイル

- `index.html`：現在の完成版
- `service-worker.js`：オフラインキャッシュ
- `assets/trainers/`：3人の既定トレーナー画像
- `manifest.webmanifest`：PWA設定
- `kemotore_spec.md`：既存仕様書
- `調査とv6変更点.md`：参考アプリの調査と設計判断
- `archive/`：改修前のHTML。通常は使用しません
